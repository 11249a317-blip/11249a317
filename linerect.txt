Aim:
To write a Java Applet program to draw lines, rectangles, filled rectangles, rounded rectangles and intersecting lines using Graphics class.
Algorithm:
1. Start the program.
2. Import the required packages such as java.awt.*, java.io.* and java.applet.*.
3. Create a class named linerect that extends the Applet class.
4. Override the paint(Graphics g) method.
5. Use drawLine() to draw straight lines.
6. Use drawRect() to draw an unfilled rectangle.
7. Use fillRect() to draw a filled rectangle.
8. Use drawRoundRect() to draw an unfilled rounded rectangle.
9. Use fillRoundRect() to draw a filled rounded rectangle.
10. Draw two intersecting lines using drawLine().
11. Run the applet and display the output.
12. Stop the program.
program:
import java.awt.*;
import java.io.*;
import java.applet.*;
/*<applet code="linerect.class" height=300 width=300>
</applet>*/
public class linerect extends Applet
{
    public void paint(Graphics g)
    {
        g.drawLine(10,10,50,50);
        g.drawRect(10,60,40,30);
        g.fillRect(60,10,30,80);
        g.drawRoundRect(10,100,80,50,10,10);
        g.fillRoundRect(20,110,60,30,5,5);
        g.drawLine(100,10,230,140);
        g.drawLine(100,140,230,10);
    }
}
Output:
The applet window displays:
- A straight line.
- An unfilled rectangle.
- A filled rectangle.
- An unfilled rounded rectangle.
- A filled rounded rectangle.
- Two intersecting diagonal lines.
Result:
Thus, the Java Applet program to draw lines, rectangles, filled rectangles and rounded rectangles using the Graphics class was successfully executed.
