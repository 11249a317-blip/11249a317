Aim:To write a Java program to read and display the contents of a text file using the FileReader class.import java.io.*;
Algorithm
1.Start the program.
2.Create a FileReader object for the file sample2.txt.
3.Declare an integer variable i to store each character read from the file.
4.Read the file character by character using fr.read().
5.Continue reading until read() returns -1, indicating the end of the file.
6.Convert each character to char and display it.
7.Close the file using fr.close().
8.If an exception occurs, display the exception message.
9.Stop the program.
class Filereader
{
public static void main(String[] args)
{

try
{
FileReader fr=new
FileReader("sample2.txt"); int i;
while((i=fr.read())!=-1)
{
System.out.println((char)i);
}
fr.close();
}
catch(Exception e)
{
System.out.println("Exception:"+e);
}
}
}
